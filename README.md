# Projet chef-d'oeuvre

| Répertoire de créatures de Jeux de rôles | Joueurs et maîtres du jeu de JdR | Centraliser la recherche de créatures pour tous jeux de rôles |

## Glossaire 

Dans les différentes documentations présentes dans ce projet, certains termes sont abrégés :
- JdR = Jeu de rôle
- MJ = Maître du Jeu

# Utilisation du projet avec Docker

Pour build une première fois le projet, puis le lancer
```bash
docker compose up --build
```

Pour juste lancer le projet déjà build
```bash
docker compose up
```

ou 

```bash
docker compose up -d
```

Down les volumes et supprimer 
```bash
docker compose down -v
```
